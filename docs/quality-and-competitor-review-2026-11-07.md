# MYTRIP 품질·경쟁 서비스 비교

검토일: 2026-11-07 (Asia/Seoul)

## 검증 결과

- 정적 검사: JavaScript 문법, 필수 UI 연결, 중복 ID, 마크업 검사 통과
- 전체 흐름: 여행 생성 → 장소 2개 → 일정 → 충돌 경고 → 이동 정보 → 해외통화 쇼핑 → 예약 → 준비물 → JSON 백업 → Supabase 업로드 통과
- 반응형: 360px, 390px, 768px, 1440px에서 가로 넘침 0px
- 기본 접근성: 입력 라벨 누락 0건, 이름 없는 버튼·링크 0건, 페이지별 `h1` 1개, 런타임 오류 0건
- API 장애: 환율·Supabase 요청을 차단해도 저장된 일정과 직접 입력 화면이 렌더링됨
- Supabase: Data API 테이블 응답 확인, RLS 스키마 적용, publishable key만 프런트엔드에서 사용

검사 중 수정한 결함:

1. Supabase OTP의 복귀 주소를 잘못된 JSON 필드로 전달하던 문제를 `redirect_to` 쿼리로 수정
2. 업로드 직후 클라우드 목록 갱신이 `busy` 상태로 무시되던 문제 수정
3. 768px 태블릿에서 쇼핑·예약 폼이 화면보다 50px 넓던 문제 수정

## 판단

MYTRIP은 개인 여행자가 직접 일정을 세밀하게 편집하고 쇼핑 비용을 현지통화와 원화로 함께 확인하는 흐름이 분명하다. 한국에서는 네이버 지도와 티맵, 해외에서는 Google Maps로 분기하는 점도 비교 서비스보다 목적에 잘 맞는다.

가장 큰 사용성 격차는 일정과 지도를 같은 화면에서 보지 못하는 점이다. 다음 우선순위는 지도 패널과 일정 핀 연결이다. 이후 예약 이메일 자동 가져오기, 동행자 초대·권한, 공동 경비 분담 순서가 적합하다. 실시간 항공 알림과 AI 자동 일정은 외부 데이터 비용과 정확성 검증이 필요하므로 그 뒤에 두는 편이 안전하다.
