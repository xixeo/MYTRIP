# MYTRIP

주말 여행 일정, 장소, 주차 정보와 쇼핑리스트를 한 화면에서 관리하는 정적 웹사이트입니다.

```bash
npm install
npm start
```

여행, 일정, 장소, 쇼핑리스트, 예약과 준비물은 현재 브라우저의 `localStorage`에 저장됩니다.

## 장소와 일정 편집

- 날짜 탭 아래의 **+ 일정 추가**에서 저장 장소를 검색해 바로 타임라인에 배치합니다.
- 일정 추가 창에는 해당 여행의 장소 보관함에 등록한 장소만 표시됩니다.
- 검색 결과가 없으면 같은 창의 **+ 새 장소 만들기**로 등록한 뒤 일정 입력을 이어갑니다.
- 타임라인에서 순서 변경, 방문 완료, 건너뜀, 편집을 바로 실행합니다.
- 일정 사이의 이동수단·이동시간을 기록하고 하루 총 체류·이동시간을 확인합니다.
- 앞 일정의 종료·이동 예상과 다음 시작 시간이 겹치면 부족한 시간을 경고합니다.
- 숙소처럼 반복할 일정은 **일정 복제** 후 날짜와 시간만 바꿀 수 있습니다.
- 별도의 `장소 고르기` 단계는 사용하지 않습니다. 일정 추가 창에서 장소 선택까지 한 번에 처리합니다.
- `장소와 메뉴`의 **+ 새 장소**에서도 검색에 없는 장소를 보관함에 먼저 등록할 수 있습니다.
- 기존 장소 카드를 연 뒤 **내 장소로 저장·편집**을 누르면 사본을 만들어 메모와 정보를 수정할 수 있습니다.
- 한국 장소는 네이버 지도·티맵, 해외 장소는 Google Maps로 연결됩니다.

직접 등록한 장소와 일정은 브라우저에 보관됩니다. 다른 기기와 자동 동기화되지는 않습니다.

## 예약·준비물과 백업

- **여행 준비**에서 숙소·항공·식당·교통·체험 예약의 날짜, 상태, 예약번호와 링크를 보관합니다.
- 준비물에 담당자를 지정하고 완료 상태를 확인할 수 있습니다.
- **여행 목록 → 현재 여행 내보내기**에서 장소, 일정, 쇼핑, 환율 저장값, 예약과 준비물을 JSON 파일로 저장합니다.
- 다른 기기에서는 **여행 가져오기**로 해당 파일을 불러올 수 있습니다. 가져온 여행은 기존 여행을 덮어쓰지 않고 새 여행으로 만들어집니다.

## 여러 여행 관리

- 상단의 **여행 목록**에서 제목, 목적지, 국가, 시작일, 종료일을 입력해 여행을 만듭니다.
- 여행을 선택하면 해당 여행의 장소·일정·쇼핑리스트만 불러옵니다.
- 여행 정보 수정, 복제, 삭제를 지원합니다.
- 새 여행은 기존 예시 일정이 섞이지 않은 빈 상태로 시작합니다.

## Supabase 준비

클라우드 동기화를 연결할 때는 Supabase Dashboard의 **SQL Editor**에서 [`supabase/schema.sql`](./supabase/schema.sql)을 한 번 실행합니다. 이 스키마는 로그인한 사용자가 자신의 여행 스냅샷만 읽고 수정하도록 RLS를 적용합니다. 브라우저에는 publishable key만 사용하며 Secret 또는 `service_role` 키를 넣지 않습니다.
